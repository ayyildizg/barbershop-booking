# ÉLAN Beauty Lounge

Modern full-stack appointment booking system for beauty salons and barbershops.

---

## Features

### Authentication
- User registration & login
- JWT authentication
- Persistent sessions with localStorage

### Appointment System
- Create appointments
- Select services
- Select specialists
- Choose date & time
- Booked time protection

### Admin Panel
- Approve appointments
- Reject appointments
- Delete appointments
- Appointment history management

### Review System
- Customer reviews
- Star rating system
- Review history

### UI / UX
- Responsive design
- Modern glassmorphism interface
- Premium salon inspired UI
- Mobile friendly layout
